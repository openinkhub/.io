Website security protects your site, your customers' data and your reputation. Secure a business website with HTTPS, a web application firewall, regular software and plugin updates, strong logins, backups, malware scanning, monitoring and a plan for incidents. Security is both technical and operational: budget for ongoing maintenance and occasional audits.

How to secure a business website from cyber threats

  1. Use HTTPS everywhere with a valid SSL/TLS certificate that renews automatically.
  2. Keep everything updated: CMS, themes, plugins and server software.
  3. Lock down logins with strong passwords, two-factor authentication and the fewest admin accounts possible.
  4. Add a web application firewall (WAF) to block common attacks and bad bots.
  5. Back up automatically and keep copies off the server.
  6. Scan for malware and monitor uptime and file changes.
  7. Have an incident plan so you know exactly what to do if something goes wrong.

The biggest threats to business websites

  • Outdated plugins and software with known holes.
  • Weak or reused passwords and brute-force login attempts.
  • Malware and injected spam links.
  • Form and comment spam.
  • Data breaches through insecure forms or APIs.
  • Traffic floods (DDoS) that take a site offline.

HTTPS and SSL: the baseline

HTTPS encrypts data moving between a visitor's browser and your server. It protects forms and logins, avoids browser warnings and is a light ranking signal. Install a certificate, redirect all HTTP traffic to HTTPS, fix any “mixed content” and make sure the certificate renews automatically.

What is API security?

APIs connect your site to payments, CRMs and apps, so they need protection too. Good practice includes:

  • authentication with OAuth or API keys;
  • access limited to what each client needs;
  • rate limiting and input validation;
  • encryption in transit and at rest;
  • logging and regular security testing.

The OWASP API Security Top 10 is a useful checklist.

Protecting against malware, spam and data breaches

Combine prevention with a fast recovery. Prevent problems with updates, strong logins, a WAF and spam controls on forms. Recover fast with tested backups and a written plan. Test your restores regularly. A backup you have never restored is only a hope.

Common website security mistakes

  • Leaving unused plugins and old admin accounts in place.
  • Storing backups only on the same server.
  • Skipping updates because “the site works fine”.
  • No monitoring, so a hack goes unnoticed for weeks.
